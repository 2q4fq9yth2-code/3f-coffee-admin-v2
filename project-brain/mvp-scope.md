# THIRD FLOOR MVP Scope v1.0

状态：FROZEN
负责人：June

## 产品目标

让真实门店顾客在最短路径内完成一次有温度、但不复杂的体验：

情绪输入 → 咖啡推荐 → 下单 → 记录状态。

应用必须降低 June 的运营负担，而不是制造新的维护工作。

## 用户角色

### Guest
- 查看 Home、Mood、菜单。
- 可体验推荐。
- 下单前进入最小身份确认。

### Customer
- 完成下单。
- 查看自己的订单与情绪记录。
- 修改个人基础资料。

### June / Admin
- 修改营业状态。
- 管理菜单、价格、上下架和售罄。
- 查看与处理订单。
- 查看基础经营数据与活动报名。

## 4 页唯一目标

| 页面 | 唯一目标 | 主 CTA | 成功条件 |
|---|---|---|---|
| Home | 让顾客确认现在能否消费并进入核心路径 | 测测今天适合什么咖啡 / 直接点单 | 3 秒内看懂营业状态和入口 |
| Mood | 采集情绪并给出可解释推荐 | 查看推荐 | 推荐可跳过、可重新选择 |
| Order | 准确提交订单意图 | 确认订单 | 无重复单、金额正确、状态真实 |
| Profile | 查看个人历史状态 | 查看订单/记录 | 仅展示本人数据 |

## 当前仓库职责

`3f-coffee-admin-v2` 是 June 的运营后台。第一阶段只保证：

1. 营业状态可在 10 秒内修改。
2. 单个商品价格/上下架/售罄可在 30 秒内修改。
3. 新订单可见、可确认、可完成、可取消。
4. 所有高风险操作有明确确认与结果反馈。

## 明确不做

- 多门店、多商户。
- 复杂角色组织架构。
- 动态社区和聊天。
- 复杂积分商城、完整 Passport 等级。
- 自动营销轰炸。
- 与美团/淘宝闪购的深度双向同步，除非另立契约。

## MVP 成功指标

- 关键路径完成率：Mood → 推荐 → Order 必须可测量。
- 重复订单率：0。
- 菜单价格前后台不一致：0。
- June 修改营业状态平均操作步骤 ≤ 3。
- P0/P1 缺陷为 0 才可正式发布。
